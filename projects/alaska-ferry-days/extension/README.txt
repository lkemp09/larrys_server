ALASKA FERRY TRANSFER — CHROME OR EDGE

1. Unzip the downloaded alaska-ferry-transfer-extension.zip file.
2. Open chrome://extensions in Chrome, or edge://extensions in Edge.
3. Turn on Developer mode.
4. Choose Load unpacked.
5. Select the unzipped alaska-ferry-transfer-extension folder.
6. Reload Alaska Ferry Days.

The extension transfers route, date, passenger counts, a standard vehicle,
the selected sailing, and cabin preference to the official AMHS pages.

It never enters traveler names or payment information and never completes a
purchase. Always review AMHS availability, prices, and every selection.
